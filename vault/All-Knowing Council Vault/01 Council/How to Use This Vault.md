# How to Use This Vault

[[Home|Home]]

## Open the vault

In Obsidian's vault manager, choose **Open folder as vault** and select the `All-Knowing Council Vault` folder. Open `Home` to begin.

## Find things

Use the file explorer for folders, Quick Switcher to jump to a note, search for topics, and backlinks to see related notes. Each advisor and juror has a separate note linked to its shared instructions.

## Capture and review an idea

Duplicate the Idea Brief template, give it a descriptive title, and move it to `04 Ideas and Runs`. Fill in outcomes, constraints, resources, evidence, and unknowns. Link the brief from a new Council Run note.

The council evaluates a declared stage: exploration, bounded experiment, pilot, or deployment. Scores and evidence requirements must fit that stage. Use the Evaluation Contract for grading and voting, and the Deliberation Protocol for the complete loop and audit.

To execute the skill, use the preserved skill package in an environment with actual delegation tools. Obsidian itself stores and connects notes; it does not launch the 61 council roles. Save actual outputs, version IDs, ballots, and audit records in the run folder. Label hypothetical walkthroughs as simulations.

## Templates and attachments

Templates are ordinary notes that can be duplicated. If you enable Obsidian's built-in Templates plugin, select `05 Templates` as the template folder. Attach supporting documents in `90 Resources/Attachments` and link them from evidence notes. Community plugins are not required.

## Original resources

`90 Resources/Skill` contains an intact copy of the reusable council skill, role instructions, and Python ballot checker. The individual role notes are the reading workspace; update both the source package and relevant notes if you change the underlying instructions.
